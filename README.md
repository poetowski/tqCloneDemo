# UNTHREADED: vertical slice

*The Fates' shears are stolen. Nothing can die. You already did.*

An isometric action RPG in the spirit of Titan Quest and Grim Dawn, set in mythic
Greece. The slice is one zone, **Elaion**: an olive village above the sea, the
terraces where the dead rise, a necropolis, and the Sanctuary of the Moirai where
Khalkotauros, Hephaestus' bronze bull, guards the first blade of Atropos' shears.

Every model, animation, icon, texture, sound and music track is generated by Python
scripts running in Blender; the game runs in Godot 4.7.

## Play

```
npm run game          # title screen → Begin
```

| | |
|---|---|
| Left mouse | move / attack / pick up / talk (hold to keep going) |
| Shift + left mouse | attack in place |
| Right mouse, Q W E R | Lunge, Aspis Bash, Fate's Lash, War Cry of Ares, Bound Shades |
| 1 / 2 | healing / ichor draught |
| I · C · K | pack · hero · the Loom (skills) |
| Alt | show all loot · Esc pause · wheel zoom · F12 screenshot |

## Build

Needs Godot 4.7.2 and Blender 5.2.3 (paths in `tools/dev.mjs`) and Node 20.

```
npm run assets        # every model, icon, sound (Blender, headless)
npm run level         # the Elaion scene from the level layout
npm run verify        # load everything + 37 tests
npm run tour          # headless automated play-through of the whole zone
```
